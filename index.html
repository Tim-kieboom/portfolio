sol-lang

A systems language that keeps Rust's borrow checker and drops much of the boilerplate, with a syntax influenced by Kotlin and Swift.

Where it stands: pre-alpha. The pipeline runs from source to LLVM IR for a non-generic subset of the language. Borrow checking is in progress and generics and union types are still to come. Real programs do not compile yet.

Read the source
Ownership
Values move by default and the compiler checks borrows at compile time.
Bindings
:: for constants, := for immutable locals and mut for mutable ones, so a name tells you how it can change.
Methods
Any type can be extended with methods, primitives included.
Types
Aliases, nominal wrappers and range-limited types, with union types and match chains planned.
Concurrency
A built-in async/await runtime built around structured concurrency.

sol-shell

A status bar, wallpaper and notification daemon for Hyprland, written in QML on Quickshell. Singleton services own the system state (audio, Bluetooth, network, CPU and memory) and the UI only displays it. It includes a theme system that exports colors to Wofi, Dolphin, Thunar and Zen, and ships with a NixOS module.

  • Quickshell
  • Nix

TerminalCode

A keyboard-driven code editor that runs in the terminal, written in Rust with Ratatui. Keybindings and themes are plain JSON files, so the editor can be reshaped without recompiling.
